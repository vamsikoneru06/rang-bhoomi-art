## What this is

A React + Vite + React-Leaflet single-page app: an interactive map of India where
clicking one of 14 category-colored markers opens a museum-style detail panel
about that region's art history (historical context, artists, artworks,
significance, period). Search, category filters, and a period timeline filter
the map. Full requirements and rationale are in the spec.

## How this is being executed

Using the **superpowers:subagent-driven-development** process: a fresh
implementer subagent per task (from the plan), a task reviewer subagent
after each (spec compliance + code quality), findings either fixed in a
bounded loop or parked/ruled on, then a final whole-branch review once all
13 tasks are done.

## Decisions already made (rulings, in case they're questioned later)

- Images: CSS placeholders in v1, no real photography — `images[]` schema
  field carries `caption`/`alt` only, ready for a `src` later.
- Styling: hand-written CSS with a design-token file, not Tailwind.
- Scope: exactly the 14 locations named in the spec, no more.
- Content: historical/artist/artwork text was written from general
  knowledge at museum-label depth, not exhaustively researched.
- No automated test suite — this is a static content site with no
  business logic; verification throughout the plan is manual (dev server +
  browser checks) instead of unit tests.
- Preflight fixes applied to the plan before Task 1 ran: (a) Vite scaffold
